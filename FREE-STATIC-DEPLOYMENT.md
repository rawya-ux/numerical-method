# Free Static Page Deployment Options

Here are completely free options for deploying your numerical differentiation website with no credit card required:

## Option 1: GitHub Pages (Easiest)

### Step 1: Create a GitHub Account
- Go to [GitHub](https://github.com/) and sign up for a free account

### Step 2: Create a New Repository
- Click the "+" button in the top-right corner
- Select "New repository"
- Name it (e.g., "numerical-differentiation")
- Make it "Public"
- Click "Create repository"

### Step 3: Upload Your Files
- In the repository, click "uploading an existing file"
- Drag and drop all files from the extracted folder you downloaded
- Click "Commit changes"

### Step 4: Enable GitHub Pages
- Go to repository "Settings" (tab at the top)
- In the left sidebar, click "Pages"
- Under "Build and deployment":
  - Source: Select "Deploy from a branch"
  - Branch: Select "main" and "/root"
  - Click "Save"

### Step 5: View Your Website
- Wait a few minutes for deployment
- Your site will be available at: `https://[your-username].github.io/[repository-name]/`

## Option 2: Netlify Drop (One-Click)

### Step 1: Extract the Downloaded Files
- Find the file you downloaded from Replit
- Extract it to a folder on your computer

### Step 2: Go to Netlify Drop
- Visit [Netlify Drop](https://app.netlify.com/drop)
- You don't need to create an account

### Step 3: Drag and Drop
- Simply drag the entire folder onto the Netlify Drop page
- Wait for the upload to complete

### Step 4: Get Your Website URL
- Netlify will automatically deploy your site
- You'll get a random URL like `https://random-name-123456.netlify.app`
- Your site is now live!

## Option 3: Vercel (Simple Sign-up)

### Step 1: Create a Vercel Account
- Go to [Vercel](https://vercel.com/signup)
- Sign up with GitHub (or email)

### Step 2: Create New Project
- Click "New Project"
- Select "Import Git Repository" if using GitHub, or "Upload" if uploading directly
- Follow the prompts to deploy

### Step 3: View Your Website
- Vercel will provide a URL like `https://your-project.vercel.app`

## Important Notes

- All these options are completely FREE
- No credit card required
- Your website will have a public URL you can share with anyone
- These services host static websites indefinitely
